# Apex Corporate Performance Coaching

A responsive, static website for Apex's corporate coaching offer with Simon Johnson. All visitor-facing copy is in English.

## Preview

Open `index.html` in a browser. The page uses local photos in `images/` and Google Fonts when a visitor is online.

## Publish with GitHub Pages

1. Add these files to the root of the GitHub repository that will host Apex's site.
2. In the repository, open **Settings → Pages** and select **Deploy from a branch**, then choose the publishing branch and `/ (root)`.
3. The root `CNAME` file is set to `Apexcpc.com`. Enter the same custom domain in GitHub Pages settings and configure the DNS records GitHub specifies with your domain provider.
4. Once DNS is configured and GitHub Pages reports the domain as verified, enable HTTPS.
